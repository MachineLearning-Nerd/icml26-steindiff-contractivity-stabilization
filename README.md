# ICML 2026 reproduction: SteinDiff

Claim-by-claim audit and local reproduction record for **Mitigating the Contractivity Trap in Diffusion ODEs via Stein Stabilization**.

This repository is an independent, source-pinned audit. It is not the authors' implementation. The current evidence contains two deterministic CPU formula toys; the paper-scale sampling and FID claims remain unverified.

## What the paper does

The paper identifies a “contractivity trap” in large-step probability-flow ODE sampling: aggressive steps can make a highly expressive denoiser locally expansive, so ordinary contraction-based error suppression is not guaranteed. SteinDiff adds a training-free, inference-time correction:

    x_(k-1) = (1 - gamma_k) x_k + gamma_k T_theta(x_k)

Writing u_k = x_k - T_theta(x_k), the ideal step-wise MSE coefficient is obtained from the clean-target coupling. Stein's identity then gives the reference-free expression:

    gamma*_k =
      [(1 - 1/alpha_k) E[<u_k, x_k>]
       + (sigma_k^2 / alpha_k) E[div(u_k)]]
      / E[||u_k||^2]

The practical algorithm estimates the two batch statistics and the divergence, usually with Hutchinson probes, then clips the coefficient below by gamma_min. The paper presents this as post-hoc solver stabilization: no retraining and no reference clean samples are required at inference time. The derivation itself uses an ideal forward Gaussian coupling and is not the same thing as validating a discretized learned sampler.

## Claim-to-evidence ledger

The six claims are copied from the pinned contract in contract/live_claims.json. Paper line numbers below refer to example_paper.tex inside the pinned source archive, not to a file generated by this repository.

### Claim 1 — reference-free Stein coefficient

**Paper claim:** SteinDiff derives a reference-free estimator for the MSE-optimal correction coefficient.

**Source path:** The source defines the rectified update at lines 405–414, the ideal forward coupling at lines 422–431, the clean-target optimum at lines 433–455, and the Stein estimator at lines 479–492. The source labels the final theorem thm:stainopt_gamma; the contract calls it Theorem 4.7.

**Local production path:**

1. src/claim1_stein_identity_toy.py creates a deterministic one-dimensional Gaussian forward-coupling fixture with seed 20260802, n = 200,000, alpha = 0.8, sigma = 0.6, and a linear candidate parameter a = 1.7.
2. It computes the direct MSE-optimal coefficient and the source Stein expression from the same samples.
3. It writes the result to outputs/claim1_attempt1/results.csv and summary.json.
4. The pre-fixed pass condition is absolute difference below 0.01.

**Observed result:** direct coefficient 0.1177678981; Stein coefficient 0.1191343629; absolute difference 0.0013664648; pass = true.

**Status:** Toy passed. This does not verify a trained score model, Hutchinson estimator, discretized sampler, or the theorem for the paper's data distributions.

### Claim 2 — step-wise error decay

**Paper claim:** The contract attributes the bound

    E_0^Stein <= (1 - eta)^N E_N

to Theorem 4.8.

**Source path:** The pinned source labels the theorem thm:mse_decay and gives the definitions, one-step identity, trajectory product, and eta bound at lines 534–635. The numeric theorem label in the contract is retained for traceability; the source label is the authoritative anchor.

**Local production path:**

1. src/claim2_stepwise_decay_toy.py creates 50,000 paired one-dimensional particles with seed 20260802, four steps, lambda = 0.35, and candidate noise standard deviation 0.25.
2. At each step it computes u_k, b_k, c_k, gamma*_k, rho_k, and the exact MSE identity from a synthetic noisy affine candidate.
3. It compares the measured trajectory with the product formula and eta upper bound.
4. It records vanilla gamma = 1 and wrong-sign controls in outputs/claim2_attempt1/results.csv.
5. The protocol and source mapping are recorded in outputs/claim2_attempt1/PROTOCOL.md and SOURCE_MAPPING.md.

**Observed result:** maximum one-step identity error 2.78e-17; trajectory-product error 1.39e-17; eta bound = true; pass = true.

**Status:** Toy passed. This is not learned SteinDiff inference, Algorithm 1, image generation, FID evaluation, or a universal theorem verification.

### Claim 3 — LSUN-Bedrooms FID

**Paper claim:** At 256 x 256 LSUN-Bedrooms and 5 NFE, FID changes from 21.29 for DPM-Solver++ (2m) to 7.64 for SteinDiff (SC).

**Source path:** Table label tab:ldm_lsun_beds, source lines 882–903. The same table reports 20-NFE values of 3.25 and 2.77.

**Local production path:** None. No LSUN model, sampler run, generated sample set, or FID computation is stored here.

**Status:** Unverified paper result.

### Claim 4 — ImageNet FID reduction

**Paper claim:** ImageNet 64 x 64 shows FID reductions up to 45.8% across solver comparisons.

**Source path:** Table label tab:sampler_comparison_with_improv, source lines 1805–1864. The largest displayed FID improvement is the logSNR, three-step Heun comparison: 230.05 to 124.69, reported as 45.8%. The table also reports DPM-Solver++ and UniPC comparisons under logSNR and EDM schedules.

**Local production path:** None. No ImageNet model, generated samples, FID/FD-DINOv2 evaluator, or solver benchmark is stored here.

**Status:** Unverified paper result.

### Claim 5 — Algorithm 1 and Hutchinson implementation

**Paper claim:** Algorithm 1 uses batch statistics s_xu, s_uu, and s_div; Hutchinson trace estimation for the divergence; and a lower clip gamma_min.

**Source path:** The pseudocode is at source lines 665–682. The estimator details are at lines 683–706. The experimental setup says five random vectors were used for the reported divergence estimate at line 2008, and the implementation discussion appears at lines 2082–2093.

**Local production path:** The repository audits the source text and preserves the paper archive, but does not contain the authors' PyTorch module or an independent high-dimensional implementation.

**Status:** Source-supported, implementation unverified.

### Claim 6 — solver and benchmark coverage

**Paper claim:** SteinDiff is evaluated with DPM-Solver++, UniPC, and Heun on CIFAR-10, ImageNet 64 x 64, and LSUN-Bedrooms 256 x 256 using FID, IS, and FD-DINOv2 over few-step budgets.

**Source path:** Experimental setup at source lines 2007–2017 names the datasets, solvers, metrics, 50,000-sample FID evaluation, GPU hardware, and five Hutchinson probes. The LSUN table spans 5–20 NFE; the ImageNet comparison table uses solver step counts 3–13; CIFAR-10 results are shown in the source figures.

**Local production path:** None for the paper-scale benchmark matrix.

**Status:** Source-supported, benchmark reproduction unverified.

## Reproduction boundary

This repository uses the following labels:

- **Source-supported:** the pinned paper source contains the claimed statement or procedure at the cited anchor.
- **Toy passed:** a reduced deterministic fixture passed its pre-specified checks.
- **Reproduced:** the paper-scale protocol, inputs, implementation, metrics, and outputs have been independently run and archived.
- **Unverified:** the claim may be present in the paper, but this repository has not established it through a complete local evidence path.

Only the first two labels currently apply. In particular, the values 7.64, 45.8%, and the full solver/benchmark matrix are paper-reported values, not local measurements from this repository.
